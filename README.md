# CS Map

단편적인 컴퓨터공학 지식을 실제 시스템의 동작 흐름 안에서 연결해 보여주는 클릭 기반 Semantic Zoom 학습 서비스다.

사용자는 하나의 World Viewport에서 Topic을 클릭하며 내부 Scene으로 이동하고, 지도 옆 Explanation Panel에서 자세한 설명과 퀴즈를 함께 볼 수 있다.

## 문서 읽는 순서

이 README를 읽은 다음 공통 문서를 순서대로 읽는다.

1. [프로젝트에서 사용하는 단어](./docs/WORDS.md)
2. [제품 요구사항](./docs/REQUIREMENTS.md)

Frontend를 실행하거나 코드를 수정할 때는 다음 순서로 이어서 읽는다.

1. [Frontend 실행과 구조](./frontend/README.md)
2. [기술 설계](./docs/TECHNICAL_DESIGN.md)
3. [코드 작성 가이드](./docs/CODE_GUIDE.md)

콘텐츠를 작성할 때는 공통 문서 다음에 [콘텐츠 작성 가이드](./docs/CONTENT_GUIDE.md)를 읽는다.

AI 에이전트는 먼저 [루트 에이전트 지침](./AGENTS.md)을 읽고, 안내된 [역할별 에이전트 지침](./agents)을 따른다. 이후 맡은 작업에 맞는 위 문서를 같은 순서로 읽는다.
