# DNS 이름 확인

## 개요

DNS는 계층적인 이름 공간과 리소스 레코드를 여러 이름 서버에 분산해 관리합니다. 애플리케이션은 보통 resolver에 이름 확인을 요청하며, resolver가 캐시를 확인하거나 이름 서버에 하나 이상의 질의를 보냅니다.

## UDP와 TCP

RFC 1035는 DNS가 UDP와 TCP의 서버 포트 53을 사용할 수 있다고 규정합니다. 이 학습 경로에서는 일반적인 UDP 질의를 먼저 확대하지만, 모든 DNS 통신이 항상 UDP만 사용하는 것은 아닙니다.

## 다음 장면

UDP DNS 질의를 선택하면 DNS 메시지가 datagram으로 전달되기 위해 Socket API와 커널 네트워크 계층을 거치는 흐름을 볼 수 있습니다.
