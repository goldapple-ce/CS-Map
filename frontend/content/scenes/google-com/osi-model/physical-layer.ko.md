# 한눈에 보기

물리 계층은 Bit를 전기 신호, 빛 또는 무선 신호로 표현해 실제 전송 매체로 보내는 계층입니다.

LAN Cable, 광 Fiber, Wi-Fi의 Radio Signal과 Network Interface의 물리적 연결이 이 계층과 관련됩니다.

물리 계층은 데이터의 HTTP 의미나 IP 주소를 해석하지 않습니다. Bit를 실제 신호로 전달하는 데 집중합니다.

---

# 개발자가 개입하는 지점

Application 개발자가 물리 계층을 직접 제어할 일은 거의 없습니다. 그럼에도 Cable 단선, Wi-Fi 신호 약화와 Network Interface 연결 문제는 Application 수정으로 해결할 수 없다는 점을 구분하는 데 도움이 됩니다.
