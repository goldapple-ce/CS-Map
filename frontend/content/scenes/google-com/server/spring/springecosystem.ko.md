# 개요

Spring 생태계는 Spring Framework와 그 위에서 특정 문제를 해결하는 여러 프로젝트를 함께 가리킵니다. 하나의 실행 모듈이나 단일 Container를 뜻하지 않습니다.

Spring Framework는 IoC Container, AOP, transaction, data access와 Web MVC 같은 기반 기능을 제공합니다. Spring Security는 인증·인가, Spring Data는 데이터 접근 추상화, Spring Batch는 batch 작업을 담당합니다. Spring Boot는 이 구성 요소들을 빠르게 조합할 수 있도록 자동 설정과 실행 환경을 제공합니다.

각 프로젝트는 역할이 다르지만 Spring Container에 구성 요소를 Bean으로 등록하고 의존성 주입과 lifecycle 관리를 함께 활용할 수 있습니다.
