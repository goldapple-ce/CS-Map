# 한눈에 보기

Storage는 Program, 설정과 File을 전원이 꺼진 뒤에도 보관하는 Hardware입니다. SSD와 HDD가 대표적입니다.

Browser 실행 파일과 Profile, 내려받은 File 및 여러 형태의 Browser Data가 Storage에 저장될 수 있습니다. 실행에 필요한 Code와 Data는 Storage에서 Memory로 읽혀 사용됩니다.

---

# 개발자가 개입하는 지점

Web 개발자는 Browser가 허용하는 범위에서 Cache Storage, IndexedDB와 File API 같은 저장 기능을 사용할 수 있습니다.

저장 공간은 무제한이 아니며 Browser 정책과 사용자 설정에 따라 Data가 삭제될 수 있습니다. 중요한 Server Data의 유일한 원본처럼 사용하면 안 됩니다.
