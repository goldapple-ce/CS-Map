# 한눈에 보기

Java Source는 개발자가 작성하고 Java Compiler에 건네는 `.java` 파일입니다.

```java
int result = a + b * 10;
```

이 코드는 아직 JVM이 실행할 명령이 아닙니다. Compiler는 먼저 글자를 의미 있는 조각으로 나눕니다. 다음 단계인 Lexing이 이 일을 합니다.
