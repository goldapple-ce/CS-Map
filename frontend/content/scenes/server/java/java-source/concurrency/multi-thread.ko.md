# Multi Thread란?

멀티스레드(Multi Thread)는 하나의 프로세스에서 `여러 스레드를 사용하여 작업을 수행하는 방식`입니다.
멀티스레드를 이해하기 위해서는 먼저 프로세스와 스레드의 차이를 알아야 합니다.

---

# Process와 Thread

`프로세스(Process)`는 실행 중인 `프로그램의 인스턴스`입니다. 운영체제는 각 프로세스에 독립적인 가상 주소 공간과 실행에 필요한 자원을 제공합니다.
`스레드(Thread)`는 프로세스 내에서 `실행되는 작업의 흐름`이자 CPU 스케줄링의 기본 단위입니다.
하나의 프로세스는 여러 스레드를 가질 수 있으며, 각 스레드는 독립적인 실행 흐름과 스택을 가지지만 프로세스의 힙 메모리와 자원을 공유합니다.
Java에서는 이러한 스레드를 이용하여 여러 작업을 동시에 진행할 수 있습니다.

---

# 멀티스레드와 동시성

하나의 프로세스에서 여러 스레드가 실행되는 환경을 멀티스레드(Multithread) 환경이라고 합니다.
멀티스레드 환경에서는 여러 스레드의 실행이 시간적으로 겹쳐 진행될 수 있습니다. 이를 동시성(Concurrency)이라고 합니다.

여기서 동시성과 병렬성은 구분할 필요가 있습니다.

- 동시성(Concurrency): 여러 작업의 실행이 시간적으로 겹쳐 진행되는 것입니다.
- 병렬성(Parallelism): 여러 작업이 물리적으로 같은 시점에 실행되는 것입니다.

예를 들어 하나의 CPU 코어에서 여러 스레드를 번갈아 실행하는 경우에도 동시성이 성립합니다. 반면 여러 CPU 코어에서 각각의 스레드가 실제로 동시에 실행된다면 병렬성에 해당합니다.
즉, 동시성은 여러 작업을 함께 진행하는 개념이고, 병렬성은 여러 작업을 실제로 동시에 실행하는 개념입니다. 두 개념은 서로 배타적이지 않으며 함께 성립할 수도 있습니다.

멀티스레드 환경에서 중요한 점은 여러 `스레드의 실행 순서가 항상 보장되는 것은 아니라는 사실`입니다.
특히 여러 스레드가 동일한 데이터를 공유하고 변경한다면 실행 순서에 따라 예상하지 못한 결과가 발생할 수 있습니다.
