# 한눈에 보기

Java Source는 개발자가 `.java` 파일에 작성하는 코드입니다. 현재 Scene은 Java 코드에서 객체를 바라보는 관점과 HashMap의 내부 구조를 각각 살펴보는 두 진입점을 보여줍니다.

두 Node 사이에는 실행 순서나 상속 관계가 표시되어 있지 않습니다. 서로 다른 주제를 독립적으로 선택해 학습하는 구조입니다.

---

# 현재 구성

- `Object Oriented Programming`: 객체와 Class를 중심으로 Java 코드를 구성하는 관점을 설명합니다.
- `HashMap`: Key로 Value를 찾는 과정과 Hash, Bucket, Collision 같은 내부 구조를 하위 Scene에서 설명합니다.

현재 화면은 두 개념의 처리 흐름을 나타내는 것이 아니라 Java Source 아래에 배치된 학습 주제를 보여줍니다.
