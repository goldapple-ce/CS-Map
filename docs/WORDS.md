# CS Map에서 사용하는 단어

사용자와 에이전트가 제품의 화면, 탐색과 콘텐츠 구조를 같은 말로 설명하기 위한 용어 기준이다. 제품 동작은 [제품 요구사항](./REQUIREMENTS.md), 시스템 구조는 [아키텍처](./ARCHITECTURE.md)를 따른다.

## 사용 원칙

- 용어명은 아래에 적힌 영어 표현을 사용한다.
- Class, 함수와 필드 같은 코드 식별자는 실제 이름을 유지한다.
- 공간 탐색을 `페이지`, `슬라이드`, `depth 화면`으로 표현하지 않는다.
- 이 문서가 요구사항이나 아키텍처와 다르면 요구사항과 아키텍처를 따른다.

## 핵심 구조

CS Map에서 지식과 흐름을 구성하는 기본 단위를 정의한다.

- `Topic:` 사용자가 선택하거나 더 자세히 탐색할 수 있는 지식 대상이다.
- `Scene:` Topic의 내부 구조나 동작 흐름을 보여주는 공간이자 콘텐츠 단위다.
  - `Child Scene:` 특정 Topic을 통해 들어갈 수 있는 하위 Scene이다.
  - `Scene Area:` 같은 범위에 속하는 여러 Topic을 시각적으로 묶는 배경이다. 클릭하거나 진입하는 대상은 아니다.
  - `Node:` Scene 안에 배치되는 Topic의 표현이다. Topic은 지식 대상을, Node는 화면에 놓인 요소를 강조하는 말이다.
  - `Edge:` 두 Node 사이의 데이터 이동이나 실행 순서를 보여주는 선과 화살표다.

## 제품과 화면

사용자가 Topic을 탐색하고 설명을 읽는 화면을 정의한다.

- `Explorer:` 지도를 탐색하고 설명을 읽는 사용자 경험 전체다.
  - `World Viewport:` Topic과 Edge를 배치한 지도를 보여주는 영역이다.
  - `Explanation Panel:` 현재 Topic의 긴 설명과 퀴즈를 보여주는 영역이다.

## 공간 탐색

World Viewport에서 원하는 Topic으로 이동하고 세부 내용을 보여주는 방식을 정의한다.

- `Camera:` World Viewport가 어느 위치를 어느 크기로 보여줄지 나타내는 상태다.
  - `Bounds:` Topic이나 Scene이 차지하는 직사각형 범위다.
  - `Semantic Zoom:` 확대 정도에 따라 Topic의 내부 구조와 세부 정보를 단계적으로 보여주는 탐색 방식이다.
    - `LOD:` 화면에 보이는 크기에 따라 어느 정도의 정보를 표시할지 정하는 단계다. `Level of Detail`의 약자다.
